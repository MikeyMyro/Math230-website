# MLB Fastball Analysis

An interactive analysis of 2021 MLB four-seam fastballs using Baseball Savant data.

The website explores how velocity and pitch movement influence fastball effectiveness, including:

- Velocity, ride, run, and cut fastball profiles
- Expected results and swing-and-miss metrics
- Run Value per 100 pitches
- A breakdown of the top 10 four-seam fastballs of 2021

Built with R, tidyverse, ggplot2, and Distill.
